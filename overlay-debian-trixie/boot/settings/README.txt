## The OpenFrame's settings

# Each file sets one part of the OpenFrame, and can be edited on any computer. Each
# explains itself inside; most can be changed in Settings on the screen too.
#
#   wifi.txt       The Wi-Fi network to join, and its password.
#   ethernet.txt   A fixed address for the wired network (or leave it to the router).
#   name.txt       The OpenFrame's name on your network.
#   interface.txt  The touch screen: the app to open at start, the clock, screensaver
#                  and screen off.
#   backlight.txt  How automatic brightness follows the room.
#   audio.txt      Where the sound goes (a USB DAC, say).
#   updates.txt    When the OpenFrame installs its updates.
#   ssh.txt        Signing in from another computer (SSH).
#   flash.txt      Installing a fresh system onto the internal memory.
#   test.txt       Taking OpenBeak's updates before they're released.
#   shares.txt     Network shares with music, for services such as a music server.
